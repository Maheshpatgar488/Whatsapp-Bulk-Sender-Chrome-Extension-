2. Quota Check & "Quota Over" Popup System

Architectural flow for checking user credits before sending each message:

  • Pre-Send Inspection: When user clicks "Start Bulk Sending", the extension verifies remaining quota in local storage / backend.
  • Type Verification: If an image/video/PDF is attached, deducts 1 Attachment Credit. If plain text, deducts 1 Text Credit.
  • Quota Exhaustion Intercept: If quota reaches 0 during a campaign, sending pauses immediately and triggers the Quota Over Modal.

3. Payment & Owner Renewal Workflow

The 4-step loop for user payment processing and manual/automated owner renewal:

  • User Action: User clicks "Pay & Renew Plan" in the popup. A custom payment dialog opens showing your **UPI QR Code** / **GPay/PhonePe** / **Razorpay Link**.
  • Submission: User completes payment and submits their Phone Number & Transaction Reference ID.
  • Owner Notification: You (the owner) instantly receive an alert on Telegram / Email / Admin Dashboard:
    "🔔 New Payment Received from Mahesh Patgar (+919967949880) - Txn ID: UPI123456789 - Plan: 2,000 Text + 500 Media"
  • Owner Top-Up: You verify payment, open your Admin Portal or Google Sheet master table, enter the user's phone number/key, and click "Approve Top-Up".
  • Extension Unlock: The user's extension automatically fetches the updated balance and unlocks sending instantly!
