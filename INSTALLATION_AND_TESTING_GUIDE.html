WhatsApp Bulk Sender

User Installation & Testing Guide

Version 1.2
📌 What This Tool Does: Automatically sends personalized WhatsApp messages & media attachments (Photos, Videos, PDFs, Documents) in bulk from Excel (.xlsx), .csv, or Phone Contact (.vcf) files with human-like safety delays and live status export.

1 Extract the ZIP File

  1. Save the whatsapp-bulk-sender.zip file onto your laptop.
  2. Right-click the zip file and choose Extract All... (or Extract Here).
  3. You will get a folder containing files like manifest.json, popup.html, popup.js, contacts.csv, etc.

2 Install in Google Chrome (Takes 30 Seconds)

  1. Open Google Chrome.
  2. In the URL bar, type: chrome://extensions and press Enter.
  3. Turn ON the toggle for Developer mode (located in the top-right corner).
  4. Click the Load unpacked button (in the top-left corner).
  5. Select the extracted folder and click Select Folder.
  6. (Recommended) Click the Chrome extensions icon (🧩 puzzle piece) at the top-right and click the 📌 pin icon next to WhatsApp Bulk Sender.

3 Open WhatsApp Web

  1. Open a tab and go to: https://web.whatsapp.com
  2. Log in with your WhatsApp account by scanning the QR code.
  3. Keep this tab open.

4 Test Option A: Safe Simulation (Zero Messages Sent)

Goal: Verify file upload, dynamic variables, and preview without messaging anyone.

  1. Click the WhatsApp Bulk Sender icon on your Chrome toolbar.
  2. Click Choose File and pick contacts.csv.
  3. In the template box, write:
    Hi {name}, this is a test message from {company}!
  4. Ensure 🧪 Safe Test Mode (Dry Run) is CHECKED.
  5. Click 🧪 Run Safe Test (Dry Run).
  6. Watch the live log and counters update. Click Export Delivery Report (.xlsx) when done.

5 Test Option B: Real Live Sending Test

Goal: Send an actual test message to yourself or a colleague.

  1. Open contacts.csv in Notepad or Excel.
  2. Add your phone number (with country code, no + sign or spaces):
    Name,Phone,Company,Offer
    John Doe,919876543210,My Company,20% Discount
  3. Save the file.
  4. Open the extension popup, upload your edited file, and UNCHECK the Safe Test Mode box.
  5. Click 🚀 Start Live Bulk Sending.
  6. WhatsApp Web will navigate to your chat and automatically send the message.

6 WhatsApp Anti-Ban Best Practices

Safety Rule Recommended Setting Why It Matters
Delay Pacing Min: 8s | Max: 15s Simulates natural human typing and prevents automated bot triggers.
Personalization Use {name}, {company} Prevents duplicate message spam detection by Meta filters.
Audience Existing customers / Inquiries Reduces user "Report Spam" clicks to 0%.
